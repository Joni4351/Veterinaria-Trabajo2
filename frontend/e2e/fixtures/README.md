# Imagen de prueba

`bbt1.jpg` procede de los ejemplos oficiales de face-api.js, commit
`a86f011d72124e5fb93e59d5c4ab98f699dd5c9c`:
https://github.com/justadudewhohacks/face-api.js/blob/a86f011d72124e5fb93e59d5c4ab98f699dd5c9c/examples/images/bbt1.jpg
